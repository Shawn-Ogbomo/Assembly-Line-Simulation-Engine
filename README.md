# Seneca Polytechnic: Object-Oriented Software Development & Capstone

This repository houses my core programming laboratories, technical milestones, and final capstone project completed during the Computer Programming (CPD) curriculum at Seneca Polytechnic. 

## 🚀 Featured Project: Discrete Event Simulation Engine
The final application framework for the curriculum is located in the [oop_345_project](./oop_345_project) directory. 

* **Description:** A multi-stage production line simulation utilizing STL sequence containers (`std::deque`, `std::vector`) to orchestrate execution pipelines.
* **Memory Strategy:** Enforces single-ownership boundaries via `std::unique_ptr` to eliminate dynamic heap resource leaks under fluctuating simulation loops.
